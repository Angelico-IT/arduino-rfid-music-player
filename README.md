# Arduino Disco Countdown 🎵

## Description

This Arduino project combines a 3-2-1 countdown with colorful LED effects and the Tetris theme song played through a buzzer.

After the countdown, the circuit enters a disco mode with flashing LEDs, random 7-segment display patterns, and synchronized music.

## Features

- 3-2-1 countdown
- Two flashing LEDs
- Buzzer plays the Tetris theme
- Random disco light effects
- 7-segment display animation

## Components

- Arduino Uno
- 7-Segment Display
- LEDs
- Resistors
- Passive Buzzer
- Jumper Wires
- Breadboard

## Pin Connections

| Component | Pin |
|-----------|----:|
| LED 1 | 6 |
| LED 2 | 5 |
| Buzzer | 4 |
| Digit 1 | 10 |
| Digit 2 | 8 |
| Digit 3 | 7 |
